# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue with details that could help someone exploit a vulnerability.

Include the affected file or command, the steps needed to reproduce the issue,
and any suggested mitigation. The project does not promise a response time, but
reports will be reviewed by the maintainers.

## Supported versions

Only the current default branch is supported. Older checkouts may not include
the latest security fixes.
